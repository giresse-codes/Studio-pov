# DevsTeach 7 — « Ça casse sur téléphone »

**Style de voix : jeune et complice, rythme rapide, pédagogue sur les explications.**

## Voix off

```
[choqué] Parfait sur ordinateur… catastrophique sur téléphone.
[complice] Mardi. Max t'envoie la capture du client : trois cartes minuscules, collées côte à côte. Il faut zoomer avec deux doigts pour lire.
[explique] Aujourd'hui, la plupart des visiteurs arrivent sur téléphone. Un site qui ne s'adapte pas, ils le quittent en trois secondes.
[rapide] Soit tu crées un deuxième site, spécial téléphone. Soit tu rends celui-ci responsive.
[défi] Tu ferais quoi ?
[pause]
[explique] Deux sites, c'est deux fois plus de travail et de bugs. Un seul site qui s'adapte, c'est la norme.
[pédagogue] Un : sur le conteneur des cartes, display flex et flex-wrap wrap. Les cartes passent à la ligne quand il n'y a plus de place. Deux : une media query, « sous 600 pixels, chaque carte prend toute la largeur ». Trois : la balise meta viewport dans le head.
[malin] Sans le viewport, le téléphone fait semblant d'être un ordinateur et affiche tout en minuscule.
[satisfait] Sur téléphone, les cartes s'empilent. Le client répond avec trois emojis feu.
[teaser] Demain : un bouton qui ne fait… rien du tout.
```

**Choix :** 🟢 Un deuxième site / 🔴 Le rendre responsive (bonne réponse : 🔴, afficher `display:flex`, `flex-wrap:wrap`, `@media (max-width:600px)`, la meta viewport)

**Hook :** 3 réglages et ton site marche sur tous les téléphones 🔥

**Légende :** Flexbox, media query, viewport : le trio du responsive. Enregistre 👇
