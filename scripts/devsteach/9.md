# DevsTeach 9 — « Le formulaire de contact »

**Style de voix : jeune et complice, rythme rapide, pédagogue sur les explications.**

## Voix off

```
[désespéré] 40 messages reçus… et aucun n'est utilisable.
[complice] Jeudi. Des emails sans arobase, des numéros avec des lettres, et un message vide signé « Bobo ».
[explique] Un formulaire, c'est la balise form avec des champs input. Par défaut, il ne vérifie rien.
[rapide] Soit tu utilises les vérifications intégrées au HTML. Soit tu tries tous les messages à la main.
[défi] Tu ferais quoi ?
[pause]
[pédagogue] Le HTML fait le videur gratuitement. required sur chaque champ obligatoire : impossible d'envoyer vide. type égal email : le navigateur vérifie l'arobase. type égal tel pour le numéro. minlength pour un message assez long.
[malin] Bonus : sur téléphone, type email affiche directement le clavier avec l'arobase.
[sérieux] Mais un petit malin peut contourner ces vérifications. Plus tard, on vérifiera aussi côté serveur, avec PHP.
[amusé] Bobo réessaie. Il écrit « salut ». C'est un début.
[teaser] Demain : tout le code disparaît.
```

**Choix :** 🟢 Les vérifications HTML / 🔴 Trier à la main (bonne réponse : 🟢, afficher `required`, `type="email"`, `type="tel"`, `minlength`)

**Bandeau :** JEUDI • 09:05 / Bureau – Startup / Toi, stagiaire dev

**Hook :** Le videur gratuit de ton formulaire s'appelle required 🚪

**Légende :** 4 attributs HTML pour un formulaire propre. Enregistre 👇
