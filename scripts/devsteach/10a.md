# DevsTeach 10a — « Tout le code a disparu »

```
[calme] Vendredi soir. Tu fermes ton ordinateur, fier de ta semaine.
[choqué] Lundi matin. Ton ordinateur refuse de démarrer. Écran noir.
[lit, terrifié] Max : « Dis-moi que tu as une copie du site. DIS-LE-MOI. »
[petite voix] Ta seule copie… c'est une clé USB. Avec la version d'il y a trois semaines.
[explique] Les vrais développeurs ne perdent jamais leur code. Ils utilisent un outil qui garde chaque version, et une copie en ligne.
[tendu] Le réparateur dit qu'il peut peut-être récupérer le disque. Peut-être.
[rapide] Pour la suite, deux options. Soit tu fais une copie sur clé USB tous les vendredis. Soit tu utilises Git et GitHub.
[défi] Tu ferais quoi ?
```

**Choix :** 🟢 Clé USB chaque vendredi / 🔴 Git et GitHub

**Hook :** Mon ordinateur est mort… avec tout le code du client dedans 💀

**Légende :** Le cauchemar de tous les développeurs. Comment tu évites ça ? 👇
