# DevsTeach 10b — « Tout le code a disparu » (la réponse)

```
[soulagé] Bonne nouvelle : le réparateur a sauvé le disque. Mais plus jamais ça.
[complice] La réponse : Git et GitHub.
[explique] Git, c'est un appareil photo pour ton code. Chaque fois que tu termines quelque chose, tu prends une photo : un commit, avec un petit message, du genre « ajout du formulaire ».
[pédagogue] GitHub, c'est l'album en ligne. Avec git push, tu envoies tes photos dessus. Ton ordinateur peut exploser, ton code est en sécurité.
[malin] Et si tu casses quelque chose ? Tu reviens à la photo d'avant. Comme une machine à remonter le temps.
[conseil] Les trois commandes à retenir : git add, git commit, git push. À faire tous les jours, pas tous les vendredis.
[sérieux] La clé USB, elle, se perd, se casse… et ne garde qu'une seule version.
[amusé] Max a créé un compte GitHub. Son premier commit : « plus jamais ».
[teaser] Prochain épisode : le site doit enfin être visible sur Internet.
```
