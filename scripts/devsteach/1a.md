# DevsTeach — Histoire 1, partie 1 : « Le site est moche »

**Style de voix (AI Studio) :** narrateur jeune et complice, rythme rapide, comme un pote qui te raconte une galère.

## Voix off
```
[complice] Premier jour de stage. Tu t'assois, tu poses ton café… et ton téléphone vibre.
[lit, paniqué] Max : « URGENT. Le site du client est en ligne dans une heure. Regarde-le. »
[curieux] Tu ouvres le site. Et là… [pause] [consterné] Texte noir. Fond blanc. Pas une couleur. On dirait un document Word de 1998.
[explique, posé] Un site web, c'est trois fichiers qui travaillent ensemble. Le HTML, c'est le squelette : les titres, les textes, les images. Le CSS, c'est les vêtements : les couleurs, les tailles, la mise en page. Et le JavaScript, c'est les muscles : ce qui bouge quand tu cliques.
[amusé] Là, ton site, il est tout nu.
[tendu] Ton téléphone vibre encore. Max : « 45 minutes. »
[rapide] Deux options. Soit le HTML est cassé, et tu réécris tout. Soit le fichier CSS est bien là… mais personne ne l'a relié à la page.
[défi] Tu ferais quoi ?
```

## Choix
- 🟢 Réécrire le HTML
- 🔴 Relier le CSS
