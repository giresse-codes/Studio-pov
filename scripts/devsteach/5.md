# DevsTeach 5 — « Les couleurs du client »

**Style de voix : jeune et complice, rythme rapide, pédagogue sur les explications.**

## Voix off

```
[blasé] Le client a changé d'avis trois fois… et j'ai modifié une seule ligne.
[complice] Vendredi. Le client : « Tous les boutons en orange. Sauf le bouton Acheter : lui, en vert. »
[amusé] Dans ton CSS : button, couleur orange. Résultat : tout est orange. Même Acheter.
[rapide] Soit tu ajoutes une classe au bouton Acheter, en CSS. Soit tu écris la couleur verte directement dans le HTML.
[défi] Tu ferais quoi ?
[pause]
[pédagogue] La classe. Dans le HTML : class égal btn-acheter. Dans le CSS : point btn-acheter, couleur verte.
[explique] Le point, c'est pour une classe, qu'on peut donner à plein d'éléments. Le dièse, pour un id : un seul élément unique.
[malin] Pourquoi le vert gagne ? En CSS, la règle la plus précise gagne. Une classe est plus précise que « tous les boutons ».
[sérieux] La couleur dans le HTML ? Le jour où le client change d'avis, tu fouilles toutes tes pages.
[amusé] Il veut un vert… un peu plus vert. Une ligne. Fini.
[teaser] Demain : tout est collé, plus rien ne respire.
```

**Choix :** 🟢 Une classe CSS / 🔴 La couleur dans le HTML (bonne réponse : 🟢, afficher `.btn-acheter { background: green; }`)

**Bandeau :** VENDREDI • 15:40 / Bureau – Startup / Toi, stagiaire dev

**Hook :** Le client a changé d'avis 3 fois, j'ai touché une seule ligne 😎

**Légende :** Le point pour une classe, le dièse pour un id. Tu vas t'en servir tous les jours 👇
