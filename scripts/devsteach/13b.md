# DevsTeach 13b — « Où ranger les clients ? » (la réponse)

```
[complice] La réponse : une base de données.
[explique] Imagine un classeur Excel super puissant. Chaque feuille, c'est une table. Une table clients, une table commandes. Chaque ligne, un client. Chaque colonne, une info : nom, email.
[pédagogue] Chaque client reçoit un numéro unique : son id. Et dans la table commandes, tu notes juste l'id du client. Comme ça, une commande sait toujours à qui elle appartient.
[malin] Pour parler à la base, on utilise un langage : SQL. Par exemple : SELECT étoile FROM clients WHERE email égal à telle adresse. Et en un éclair, la base te trouve le bon client parmi des milliers.
[conseil] Avec PHP, le duo classique, c'est MySQL. Ton PHP envoie la question, MySQL répond.
[sérieux] Le fichier texte, lui, devient lent, se corrompt, et deux clients qui s'inscrivent en même temps peuvent s'écraser.
[amusé] Le collègue a supprimé son fichier texte. Discrètement.
[teaser] Prochain épisode : quelqu'un a piraté le site.
```
