# DevsTeach 14a — « Le site s'est fait pirater »

```
[tendu] Lundi, 7 h du matin. Ton téléphone sonne. C'est Max.
[lit, terrifié] « Quelqu'un est entré dans l'espace membres. Il a vu les emails de tous les clients ! »
[grave] Tu regardes les journaux du serveur. Le pirate n'a pas deviné de mot de passe. Il a écrit… du code SQL directement dans le champ « email » du formulaire.
[explique] Ton PHP colle ce que tape le visiteur directement dans la requête SQL. Le pirate en a profité pour la transformer. Ça s'appelle une injection SQL.
[sérieux] Pire : dans la base, les mots de passe des clients sont écrits en clair. Lisibles.
[rapide] Deux options. Soit tu ajoutes un filtre qui bloque les mots dangereux comme SELECT ou DROP. Soit tu passes aux requêtes préparées, et tu hashes les mots de passe.
[défi] Tu ferais quoi ?
```

**Choix :** 🟢 Bloquer les mots dangereux / 🔴 Requêtes préparées + hash

**Hook :** Un pirate est entré dans le site… en tapant dans le champ email 💀

**Légende :** La faille la plus célèbre du web. Tu saurais la bloquer ? 👇
