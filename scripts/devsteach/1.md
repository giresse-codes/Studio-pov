# DevsTeach 1 — « Le site est moche »

**Style de voix : jeune et complice, rythme rapide, pédagogue sur les explications.**

## Voix off

```
[choqué] Premier jour de stage… et le site du client ressemble à un document Word de 1998.
[complice] Tu t'assois, tu poses ton café. Ton téléphone vibre. Max : « URGENT. Le site sort dans une heure. Regarde-le. »
[consterné] Tu l'ouvres. Texte noir. Fond blanc. Pas une couleur.
[explique] Un site, c'est trois fichiers. Le HTML, le squelette : titres, textes, images. Le CSS, les vêtements : couleurs, tailles, mise en page. Le JavaScript, les muscles : ce qui bouge quand tu cliques.
[amusé] Là, ton site est tout nu.
[rapide] Soit le HTML est cassé et tu réécris tout. Soit le fichier CSS existe, mais personne ne l'a relié à la page.
[défi] Tu ferais quoi ?
[pause]
[malin] Regarde : le texte s'affiche, les titres sont là. Le HTML marche très bien. Le réécrire, c'était une heure perdue.
[pédagogue] Le navigateur ne devine rien. Dans le head de ta page, tu ajoutes une seule ligne : link, rel égal stylesheet, href égal style point css.
[émerveillé] Tu rafraîchis… les couleurs, les boutons, la mise en page : tout apparaît.
[conseil] Retiens ça : site sans style ? Vérifie d'abord la balise link, et le nom exact du fichier.
[teaser] Demain, Max veut un titre… géant.
```

**Choix :** 🟢 Réécrire le HTML / 🔴 Relier le CSS (bonne réponse : 🔴, afficher `<link rel="stylesheet" href="style.css">`)

**Bandeau :** LUNDI • 09:12 / Bureau – Startup / Toi, stagiaire dev

**Hook :** Une seule ligne de code a sauvé mon premier jour de stage 😮‍💨

**Légende :** Le site sortait dans une heure et il était tout nu. Tu avais trouvé la solution avant moi ? 👇
