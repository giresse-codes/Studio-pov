# DevsTeach 10 — « Tout le code a disparu »

**Style de voix : jeune et complice, rythme rapide, pédagogue sur les explications.**

## Voix off

```
[terrifié] Mon ordinateur est mort… avec tout le code du client dedans.
[complice] Lundi matin. Écran noir. Max : « Dis-moi que tu as une copie. DIS-LE-MOI. »
[petite voix] Ta seule copie : une clé USB… d'il y a trois semaines.
[rapide] Pour que ça n'arrive plus jamais : soit une copie sur clé USB tous les vendredis. Soit Git et GitHub.
[défi] Tu ferais quoi ?
[pause]
[explique] Git, c'est un appareil photo pour ton code. Chaque fois que tu finis quelque chose, tu prends une photo : un commit, avec un message comme « ajout du formulaire ».
[pédagogue] GitHub, c'est l'album en ligne. Avec git push, tu envoies tes photos dessus. Ton ordinateur peut exploser : ton code est en sécurité.
[malin] Tu as cassé quelque chose ? Tu reviens à la photo d'avant. Une machine à remonter le temps.
[conseil] Trois commandes, tous les jours : git add, git commit, git push.
[soulagé] Le réparateur a sauvé ton disque, cette fois. Le premier commit de Max : « plus jamais ».
[teaser] Demain : le site doit enfin être visible sur Internet.
```

**Choix :** 🟢 Clé USB chaque vendredi / 🔴 Git et GitHub (bonne réponse : 🔴, afficher `git add`, `git commit -m`, `git push` et la ligne du temps des commits)

**Bandeau :** LUNDI • 08:02 / Bureau – Startup / Toi, stagiaire dev

**Hook :** L'appareil photo qui a sauvé ma carrière de développeur 📸

**Légende :** git add, git commit, git push. Tous les jours. Partage à un ami qui code 👇
