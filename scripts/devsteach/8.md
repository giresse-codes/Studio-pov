# DevsTeach 8 — « Le bouton ne fait rien »

**Style de voix : jeune et complice, rythme rapide, pédagogue sur les explications.**

## Voix off

```
[agacé] J'ai cliqué vingt fois sur ce bouton. Il ne se passe RIEN.
[complice] Mercredi. Le client veut un bouton « Afficher plus » qui montre la suite du texte. Ton bouton est beau, vert… et mort.
[explique] Le HTML affiche le bouton. Le CSS l'habille. Mais pour réagir au clic, il faut des muscles : le JavaScript.
[rapide] Soit un lien qui recharge une autre page avec le texte complet. Soit quelques lignes de JavaScript qui écoutent le clic.
[défi] Tu ferais quoi ?
[pause]
[explique] Recharger toute une page pour trois lignes, c'est lent, et ça clignote.
[pédagogue] En JavaScript, trois étapes. Tu attrapes le bouton avec document point querySelector. Tu lui dis d'écouter, avec addEventListener et le mot click. Et tu écris ce qui se passe : montrer le texte caché.
[malin] C'est ça, un événement : le code attend un clic, une touche, un scroll… et il réagit.
[conseil] Ça ne marche pas ? Appuie sur F12 et ouvre la console. Les erreurs sont écrites en rouge.
[amusé] Le texte apparaît. Max clique quarante fois pour s'amuser.
[teaser] Demain : le formulaire de contact reçoit n'importe quoi.
```

**Choix :** 🟢 Recharger une autre page / 🔴 Écouter le clic en JavaScript (bonne réponse : 🔴, afficher `querySelector`, `addEventListener('click', …)`, la console F12)

**Bandeau :** MERCREDI • 10:30 / Bureau – Startup / Toi, stagiaire dev

**Hook :** 3 lignes de JavaScript pour donner vie à un bouton 💪

**Légende :** Attraper, écouter, réagir : tout le secret des événements. Enregistre 👇
