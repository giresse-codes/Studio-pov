# DevsTeach 12a — « Le formulaire doit envoyer des mails »

```
[complice] Mercredi. Le formulaire vérifie bien les champs. Mais quand on clique sur Envoyer…
[consterné] Les messages ne vont nulle part. Ils disparaissent.
[lit, inquiet] Max : « Le client dit qu'il ne reçoit rien. Il croit que personne ne le contacte. »
[explique] HTML, CSS, JavaScript : tout ça tourne dans le navigateur du visiteur. Mais pour envoyer un email, il faut un programme qui tourne sur le serveur.
[hésitant] Un collègue te dit : « Mets le mot de passe de la boîte mail dans le JavaScript, et envoie depuis le navigateur. »
[rapide] Deux options. Soit tu suis ton collègue. Soit tu écris un petit script PHP sur le serveur, qui reçoit le formulaire et envoie l'email.
[défi] Tu ferais quoi ?
```

**Choix :** 🟢 Le mot de passe dans le JavaScript / 🔴 Un script PHP sur le serveur

**Hook :** Le client ne reçoit aucun message depuis une semaine 📬

**Légende :** Le formulaire marche… mais les messages s'envolent. Tu ferais quoi ? 👇
