# DevsTeach 9b — « Le formulaire de contact » (la réponse)

```
[complice] La réponse : on laisse le HTML faire le videur.
[explique] Sur chaque champ obligatoire, tu ajoutes le mot required. Le formulaire refuse de partir s'il est vide.
[pédagogue] Pour l'email, tu mets type égal email : le navigateur vérifie qu'il y a un arobase et un point. Pour le téléphone, type égal tel. Et avec minlength, tu imposes une longueur minimum au message.
[malin] Bonus : sur téléphone, type email affiche directement le clavier avec l'arobase. Tes visiteurs vont adorer.
[sérieux] Attention : ces vérifications aident le visiteur, mais un petit malin peut les contourner. Plus tard, on vérifiera aussi côté serveur, avec PHP.
[satisfait] Tu testes un message vide. Le navigateur affiche : « Veuillez remplir ce champ ».
[amusé] Bobo, lui, a réessayé. Il a écrit « salut ». C'est un début.
[teaser] Prochain épisode : tout le code a disparu.
```

**Bonne réponse :** 🟢 Les vérifications HTML — afficher required, type="email", type="tel", minlength

**Hook :** Le videur gratuit de ton formulaire s'appelle required 🚪

**Légende :** 4 attributs HTML pour un formulaire propre. Et la suite côté serveur arrive bientôt 👇
