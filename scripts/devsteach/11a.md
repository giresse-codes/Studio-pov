# DevsTeach 11a — « Mettre le site en ligne »

```
[complice] Mardi. Le site est fini. Il est beau, il marche, il est sur GitHub.
[lit, excité] Max : « Envoie le lien au client ! »
[hésitant] Tu lui envoies… l'adresse de ton fichier : C, deux points, Utilisateurs, Bureau, index point html.
[amusé] Le client clique. Évidemment, rien ne s'ouvre. Ce fichier est sur TON ordinateur, pas sur Internet.
[explique] Pour qu'un site soit visible par tout le monde, il doit vivre sur un serveur : un ordinateur allumé jour et nuit, connecté à Internet.
[rapide] Deux options. Soit tu laisses ton propre ordinateur allumé en permanence pour servir le site. Soit tu passes par un hébergeur, avec un nom de domaine.
[défi] Tu ferais quoi ?
```

**Choix :** 🟢 Mon ordinateur allumé / 🔴 Un hébergeur

**Hook :** J'ai envoyé le lien du site au client… et c'était mon disque dur 😬

**Légende :** Ton site existe, mais personne ne peut le voir. Tu ferais quoi ? 👇
