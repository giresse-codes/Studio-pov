# DevsTeach 3 — « Les images ne s'affichent pas »

**Style de voix : jeune et complice, rythme rapide, pédagogue sur les explications.**

## Voix off

```
[paniqué] Toutes les photos du client ont disparu du site.
[complice] Mercredi. Max : « Le client croit qu'on a supprimé ses photos ! »
[explique] À la place : une petite icône d'image cassée, partout. Dans ton code : img, src égal photo point jpg. Mais tes photos sont rangées dans un dossier images.
[rapide] Soit tu sors toutes les photos du dossier. Soit tu corriges le chemin dans le code.
[défi] Tu ferais quoi ?
[pause]
[explique] Le navigateur suit ton chemin comme un GPS. Tu lui as dit : « la photo est juste à côté ». Il regarde à côté… rien.
[pédagogue] Il faut écrire : images, slash, photo point jpg. Le slash veut dire : entre dans ce dossier. Et point point slash : remonte d'un dossier.
[sérieux] Sortir toutes les photos, ça marche, jusqu'au jour où tu en as deux cents.
[conseil] Piège : Photo.JPG et photo.jpg, pour un serveur, ce sont deux fichiers différents.
[satisfait] Tu corriges. Toutes les photos reviennent.
[teaser] Demain : un bouton Contact qui ne mène nulle part.
```

**Choix :** 🟢 Déplacer les photos / 🔴 Corriger le chemin (bonne réponse : 🔴, afficher l'arborescence et `src="images/photo.jpg"`)

**Bandeau :** MERCREDI • 14:30 / Bureau – Startup / Toi, stagiaire dev

**Hook :** Un seul mot manquait et toutes les photos ont disparu 📁

**Légende :** Le navigateur suit ton chemin comme un GPS. Retiens le point point slash 👇
