# DevsTeach 8a — « Le bouton ne fait rien »

```
[complice] Mercredi. Le client veut un bouton « Afficher plus » qui fait apparaître le reste du texte.
[confiant] Tu as écrit le bouton en HTML. Il est beau, il est vert. Tu cliques.
[pause] [consterné] Rien. Absolument rien.
[lit, inquiet] Max : « Il marche, le bouton ? Le client attend. »
[explique] Le HTML affiche le bouton. Le CSS l'habille. Mais pour qu'il réagisse au clic, il faut des muscles : le JavaScript.
[rapide] Deux options. Soit tu ajoutes un lien qui recharge une autre page avec le texte complet. Soit tu écris quelques lignes de JavaScript qui écoutent le clic.
[défi] Tu ferais quoi ?
```

**Choix :** 🟢 Recharger une autre page / 🔴 Écouter le clic en JavaScript

**Hook :** J'ai cliqué 20 fois sur ce bouton… il ne se passe RIEN 😤

**Légende :** Un bouton sans JavaScript, c'est une décoration. Tu ferais quoi ? 👇
