# DevsTeach 3a — « Les images ne s'affichent pas »

```
[complice] Mercredi. Max t'a envoyé les photos du client. Tu les mets dans le site.
[consterné] Tu rafraîchis. À la place des photos… une petite icône d'image cassée. Partout.
[lit, paniqué] Max : « Le client vient de regarder. Il croit qu'on a supprimé ses photos ! »
[explique] Dans ton code, tu as écrit : img, src égal photo point jpg. Mais tes photos, tu les as rangées dans un dossier qui s'appelle images.
[pressé] Deux options. Soit tu sors toutes les photos du dossier pour les mettre à côté de la page. Soit tu changes le chemin dans le code.
[défi] Tu ferais quoi ?
```

**Choix :** 🟢 Déplacer les photos / 🔴 Corriger le chemin

**Hook :** Toutes les photos du client ont disparu du site 😱

**Légende :** Les photos sont là… mais le site ne les trouve pas. Tu ferais quoi ? 👇
