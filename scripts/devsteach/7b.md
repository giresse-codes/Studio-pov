# DevsTeach 7b — « Ça casse sur téléphone » (la réponse)

```
[complice] La réponse : on le rend responsive.
[explique] Deux sites, c'est deux fois plus de travail, et deux fois plus de bugs. Un seul site qui s'adapte, c'est la norme.
[pédagogue] D'abord, flexbox. Sur le conteneur des cartes, tu écris display flex, et flex-wrap wrap. Les cartes se placent côte à côte… et passent à la ligne quand il n'y a plus de place.
[malin] Ensuite, une media query : « si l'écran fait moins de 600 pixels, chaque carte prend toute la largeur ».
[conseil] Et n'oublie pas la balise meta viewport dans le head. Sans elle, le téléphone fait semblant d'être un ordinateur et affiche tout en minuscule.
[satisfait] Tu testes. Sur téléphone, les cartes s'empilent, une par une. Le texte est lisible.
[amusé] Le client envoie une nouvelle capture. Avec trois emojis feu.
[teaser] Prochain épisode : un bouton qui ne fait… rien du tout.
```

**Bonne réponse :** 🔴 Le rendre responsive — afficher display:flex, flex-wrap:wrap, @media (max-width:600px) et la meta viewport

**Hook :** 3 lignes de code et ton site marche sur tous les téléphones 🔥

**Légende :** Flexbox + media query + viewport : le trio du responsive. Enregistre 👇
