# DevsTeach 8b — « Le bouton ne fait rien » (la réponse)

```
[complice] La réponse : on écoute le clic.
[explique] Recharger toute une page pour afficher trois lignes, c'est lent. Le visiteur attend, la page clignote. Pas terrible.
[pédagogue] En JavaScript, tu fais trois choses. Un : tu attrapes le bouton avec document point querySelector. Deux : tu lui dis d'écouter, avec addEventListener, et le mot click. Trois : tu écris ce qui se passe, ici, montrer le texte caché.
[malin] C'est ça, un événement : le JavaScript attend qu'il se passe quelque chose, un clic, une touche, un scroll, et il réagit.
[conseil] Si ça ne marche toujours pas, ouvre la console du navigateur avec F12. Les erreurs sont écrites en rouge. C'est ton meilleur ami.
[satisfait] Tu cliques. Le texte apparaît en douceur.
[amusé] Max clique quarante fois pour voir. Il s'amuse.
[teaser] Prochain épisode : le formulaire de contact reçoit n'importe quoi.
```

**Bonne réponse :** 🔴 Écouter le clic — afficher querySelector, addEventListener('click', …) et la console F12

**Hook :** 3 lignes de JavaScript pour donner vie à un bouton 💪

**Légende :** Attraper, écouter, réagir : c'est tout le secret des événements. Enregistre 👇
