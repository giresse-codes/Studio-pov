# DevsTeach 5b — « Les couleurs du client » (la réponse)

```
[complice] La bonne réponse : la classe.
[explique] Dans le HTML, tu ajoutes au bouton : class égal btn-acheter. Dans le CSS, tu écris : point btn-acheter, et la couleur verte.
[pédagogue] Le point, c'est pour une classe. Une classe, tu peux la donner à autant d'éléments que tu veux. Le dièse, c'est pour un id : un seul élément unique dans la page.
[malin] Et pourquoi le vert gagne sur l'orange ? Parce qu'en CSS, la règle la plus précise gagne. Une classe est plus précise que « tous les boutons ».
[sérieux] Mettre la couleur dans le HTML, ça marche… mais le jour où le client veut changer de vert, tu dois fouiller toutes tes pages, une par une.
[satisfait] Avec la classe, tu changes une ligne, et c'est partout.
[amusé] Le client rappelle. Il veut… un vert un peu plus vert. Une ligne. Fini.
[teaser] Prochain épisode : tout est collé, plus personne ne respire.
```

**Bonne réponse :** 🟢 Une classe CSS — afficher .btn-acheter { background: green; } et la différence point / dièse

**Hook :** Le client a changé d'avis 3 fois… et j'ai modifié une seule ligne 😎

**Légende :** Le point pour une classe, le dièse pour un id. Enregistre, tu vas t'en servir tous les jours 👇
