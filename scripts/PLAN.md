# Plan des 45 vidéos

Une histoire = une seule vidéo complète (45 s à 1 min 30) : hook, situation, « Tu ferais quoi ? », réponse et explication, accroche vers l'épisode suivant. Scripts : `scripts/<chaine>/<numero>.md`.

## DevsTeach (ordre d'apprentissage, avec Max)
1. Le site est moche : HTML, CSS, JS
2. Max veut un titre géant : les balises HTML
3. Les images ne s'affichent pas : les chemins de fichiers
4. Le lien qui mène nulle part : les liens `<a>`
5. Les couleurs du client : les sélecteurs CSS
6. Tout est collé : marges, padding, box model
7. Ça casse sur téléphone : flexbox et responsive
8. Le bouton ne fait rien : JavaScript et les événements
9. Le formulaire de contact : formulaires et validation
10. Tout le code a disparu : Git et GitHub
11. Mettre le site en ligne : l'hébergement
12. Le formulaire doit envoyer des mails : PHP et le serveur
13. Où ranger les clients ? : base de données et tables
14. Le site s'est fait pirater : injection SQL et mots de passe
15. Max découvre l'IA : bien coder avec l'IA
